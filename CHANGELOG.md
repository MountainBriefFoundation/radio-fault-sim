# Changelog

## 0.1.0

- Deterministic single-queue and PTT-line model with separate feedback.
- Partial and failed writes, ownership conflicts, ignored cancellation/release,
  acknowledged-but-ineffective release, and controller crash scenarios.
- Explicit clock, bounded payloads, immutable snapshots, and nine CLI examples.
- Standalone regression tests and a small Python API.

Initial release under Apache-2.0, maintained by Mountain Brief Foundation.
